# Held-out test predictions: schema (submission artifact I)

File: [`test_predictions.csv`](test_predictions.csv), one row per **test-split** home (split by customer; see
[data/DATA_CARD.md](../data/DATA_CARD.md) §5). Regenerated by `uv run greeniq evaluate`. Empty cell = not available
(never zero-filled). kWh are annual, weather-normalised; savings = baseline − after (negative = increase).

| Column | Meaning |
|---|---|
| `property_id` | Home identifier |
| `customer_id` | Owner identifier (the split key) |
| `split` | Always `test` |
| `score` | Green Home Score 0-100 (empty when `score_status` = partial) |
| `score_status` | complete · provisional (assumed/estimated inputs) · partial (range only) |
| `band` | PS2 band (empty if a partial range spans two bands) |
| `score_range_low` | Lower end of the score range when partial |
| `score_range_high` | Upper end of the score range when partial |
| `is_poor` | True if Poor or Very poor |
| `confidence` | high · medium · low |
| `baseline_basis` | metered · estimated (model) · unavailable |
| `baseline_electricity_kwh` | Baseline grid electricity imported, kWh/yr |
| `baseline_gas_kwh` | Baseline gas, kWh/yr |
| `intensity_kwh_m2` | Purchased energy per m², kWh/m²/yr |
| `sap_used` | SAP rating used for the efficiency component |
| `sap_basis` | observed · estimated (no EPC or stale EPC adjusted) |
| `n_recommended` | Number of feasible recommended measures |
| `top_recommendation` | First measure in the recommended sequence |
| `package_measures` | Recommended package, in installation order, `|`-separated |
| `package_electricity_saving_kwh` | Package electricity saving, kWh/yr (negative = increase) |
| `package_gas_saving_kwh` | Package gas saving, kWh/yr |
| `package_net_saving_kwh` | Net purchased-energy saving, kWh/yr |
| `package_carbon_kg` | Carbon reduction, kg CO2e/yr (positive = reduction) |
| `improvement_potential_status` | available · unavailable |
| `improvement_potential_pct` | 100 × (E_baseline − E_after) / E_baseline |
| `score_after` | Green Home Score after the package |
| `epc_band_after` | Estimated EPC band after the package |
| `value_current_gbp` | Current value estimate, GBP (indicative) |
| `value_uplift_pct_low` | Indicative uplift range, low end, % (non-causal) |
| `value_uplift_pct_high` | Indicative uplift range, high end, % (non-causal) |
| `conflicts` | Data-quality conflict codes, `|`-separated |
| `floor_area_m2` | Recorded floor area |
| `metered_total_kwh` | Metered electricity + gas (empty unless baseline is metered) |
| `recorded_sap` | SAP on the recorded EPC (empty if none) |

**Labels used to grade these predictions** (not in this file; see `reports/EVALUATION.md`): weather-normalised
metered consumption, observed before/after retrofit savings, held-out sale prices, and the simulator's
counterfactual improvement potential (hidden truth, read only by the evaluation harness).
