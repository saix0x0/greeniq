# Brief Compliance Checklist

This document maps the current prototype to the Lloyds problem statement.

## Implemented

| Requirement | Current implementation |
| --- | --- |
| Calculate Green Home Score from 0 to 100 | `src/green_home/scoring.py` |
| Use fixed component weights | `COMPONENT_WEIGHTS` in `scoring.py` |
| Show component contributions | `scripts/score_properties.py`, `scripts/generate_customer_report.py` |
| Classify score | `classify_score` in `scoring.py` |
| Identify Poor and Very poor homes | `scripts/rank_poor_homes.py` |
| List key issues | `ScoreResult.key_issues` |
| Rank by improvement potential | `scripts/rank_poor_homes.py` |
| Recommend feasible retrofits only | `src/green_home/retrofits.py` |
| Prioritise interacting retrofits | insulation, glazing, heat pump, solar, smart controls order |
| Estimate electricity and gas savings separately | `FuelSavings` in `retrofits.py` |
| Avoid simple additive package savings | `_package_savings` applies retrofits sequentially |
| Show electricity increases as negative savings | heat pump logic in `retrofits.py` |
| Solar reduces grid electricity imports | solar logic in `retrofits.py` |
| Convert savings to carbon per fuel | `src/green_home/carbon.py` |
| Use emissions factors with source | `data/sample/emissions_factors.csv` |
| Estimate property-value impact as a range | `src/green_home/value.py` |
| State value estimate limitations | `ValueImpactEstimate.limitation` |
| Produce expected customer outputs together | `scripts/generate_customer_report.py` |
| Keep LLM out of calculations | calculations are deterministic Python modules |

## Prototype Assumptions

| Area | Current state |
| --- | --- |
